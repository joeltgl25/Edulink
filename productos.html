Plataforma educativa

Nuestra plataforma educativa permite agilizar, automatizar y gestionar procesos educativos en las intituciones educativas.

Caracteristicas

Edulink permite:

  • Realizar Pre-incripciones a las carrerar
  • Crear y gestionar Aulas virtuales
  • Cargar documentos y archivos multimedia
  • Publicar calificaciones
  • Realizar seguimiento de cada alumnos
  • Crear encuestas y actividades
  • Publicar notas de interes general

Plataforma Edulink

Esta plataforma consite en un sistema web convinando varias tecnologias con el fin de crear una plataforma con multiples funciones, adaptable y escalable
